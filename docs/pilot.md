# Coordinator and technician pilot

Recruit one warranty coordinator and two technicians with approval to use de-identified or synthetic cases. Allow 35–45 minutes for setup, two matched cases per technician, and coordinator review.

1. Prepare two comparable pairs of cases. Each pair has a similar repair, the same number of required fields and an evidence complication. Include same-model assets, a missing signature, and a wrong-job document across the set.
2. Give both technicians a short practice case. Technician A uses the existing workflow for the first scored case and the assistant for its matched case. Technician B uses the assistant first, then the existing workflow on the corresponding matched set.
3. Start the timer on the repair note. Stop it when the technician hands off a record for review. Record elapsed active minutes and any later correction time separately. Capture each time the technician is blocked and what action follows.
4. Give the coordinator the four closeouts in mixed order. Score each on the same checklist before giving feedback. Count a submission as first-pass complete if every relevant field and evidence item is correct and the Work Order is linked.
5. Record one concrete omission the assistant caught, if observed. Ask each technician where the workflow helped or added work. Ask the coordinator which evidence would change their review decision.

| Measure | Capture |
| --- | --- |
| Time to reviewer-ready | Start, handoff, follow-up minutes and final ready time for each case. |
| First-pass completeness | Correct items over applicable items and number of fully complete handoffs. |
| Evidence omission | Missing or wrong-job item, when it surfaced, and whether it was resolved before leaving. |

The pilot awaits participant and case approval. The evaluation report records engineering measurements for synthetic cases.
